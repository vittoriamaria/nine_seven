# ✨ Nine Seven — E-commerce de Semijoias

Projeto desenvolvido para a marca **Nine Seven**, focado na apresentação e venda de semijoias modernas e elegantes, com experiência responsiva, vitrine de produtos, carrinho de compras e área de contato integrada.

## 🌐 Visão Geral

O site foi desenvolvido com foco em:
- Design elegante e moderno
- Navegação intuitiva
- Responsividade para mobile e desktop
- Experiência de compra fluida
- Identidade visual sofisticada

---

## 🚀 Funcionalidades

### 🛍️ Catálogo de Produtos
- Listagem dinâmica de produtos
- Filtros por categoria:
  - Anéis
  - Pulseiras
  - Colares
  - Brincos

### 🛒 Carrinho de Compras
- Adição e remoção de produtos
- Atualização automática de valores
- Sidebar interativa do carrinho

### 🎞️ Banner Carrossel
- Slides promocionais automáticos
- Botões de navegação
- Destaques da coleção

### 📱 Responsividade
- Layout adaptado para:
  - Smartphones
  - Tablets
  - Desktop

### 📩 Sistema de Contato
- Formulário de contato funcional
- Armazenamento local das mensagens
- Feedback visual para o usuário

### ⚙️ Painel Administrativo
- Visualização de mensagens recebidas
- Controle de mensagens lidas/não lidas
- Exportação de dados em JSON
